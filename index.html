Audit Checks Detail

Detailed breakdown of each inclusion audit check

Check 1 Alt-Text

Alt-Text Presence Audit

Comprehensive image scanning for accessibility compliance

  1. Detection: Finds all markdown images ![alt](src) and HTML tags
  2. Validation: Checks for missing alt-text, empty alt-text, placeholder text (e.g., "image", "photo")
  3. Quality Scoring: Rates alt-text descriptiveness (1-5 scale) based on length and specificity
  4. Context Awareness: Differentiates decorative vs. informative images
  5. Output: File, line number, image src, alt-text (or missing), quality score, suggestion
Markdown + HTML Quality Scoring
Check 2 Readability

Readability Grade Analysis

Multi-metric readability assessment for educational content

  1. Flesch-Kincaid Grade Level: US school grade level required to understand text
  2. Flesch Reading Ease: 0-100 scale, higher = easier to read
  3. Gunning Fog Index: Years of formal education needed
  4. SMOG Index: Simple Measure of Gobbledygook for health/technical content
  5. Coleman-Liau Index: Character-based grade level
  6. Automated Readability Index: Character/word-based grade level
  7. Configurable Threshold: Fail if any metric exceeds target grade level
6 Metrics Configurable Threshold
Check 3 Terms

Non-Inclusive Terms Detection

Identifies problematic terminology with configurable severity and replacements

  1. Term Categories: Ableist, gendered, racially charged, ageist, mental health, socioeconomic
  2. Severity Levels: Error (must fix), Warning (should fix), Info (consider alternative)
  3. Built-in Dictionary: 200+ terms with suggested replacements
  4. Custom Dictionary: Add project-specific terms via YAML config
  5. Context Awareness: Ignores code blocks, quotes, and explicit allowlists
  6. Output: File, line, column, term, severity, suggested replacement, category
200+ Terms Custom Config
Check 4 Report

Markdown Report Generation

Structured, actionable audit reports in markdown format

  1. Summary Statistics: Files scanned, total issues, issues by severity, by category
  2. Per-File Breakdown: File path, issue count, top issues, overall score
  3. Detailed Findings: Line number, column, issue type, severity, message, suggestion
  4. Trend Tracking: Compare with previous runs, show improvement/regression
  5. CI/CD Integration: Exit codes for pipeline gates, JSON output option
  6. Filtering: Filter by severity, category, file pattern, directory

Configuration

# .inclusion-audit.yaml
readability:
  threshold_grade: 10
  metrics: ["flesch_kincaid", "gunning_fog", "smog"]

non_inclusive_terms:
  severity_overrides:
    "master": "error"
    "whitelist": "warning"
    "blacklist": "warning"
  custom_terms:
    "crazy": "warning"
    "insane": "warning"
  allowlist:
    - "blackbox"  # Technical term

alt_text:
  min_length: 10
  placeholder_words: ["image", "photo", "picture", "diagram"]
  quality_threshold: 3

output:
  format: "markdown"
  include_summary: true
  include_details: true
  trend_file: ".inclusion-trend.json"
